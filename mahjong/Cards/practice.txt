# The Tuesday Games practice card.
#
# These hands were written for this game. They are not the hands of any
# National Mah Jongg League card.
#
# Each hand is one line:  X|C  value  groups...  ; note
#   X  the hand may be exposed      C  the hand must stay concealed
#
# A group is a run of identical letters or digits. 222 is a pung of 2s,
# NEWS is four single winds, 2026 is four singles. A group of 3 or more may
# use jokers; singles and pairs may not.
#
#   1-9   a number                 0     soap (the white dragon) as a zero
#   a-i   a number that can be any 1-9: b is one more than a, c two more, ...
#   F     flower                   N E W S   winds
#   R G   red and green dragons    D     the dragon of the group's suit
#
# Numbers and D need a suit after a slash: /A, /B or /C. These stand for
# any suits, but different letters always mean different suits.
